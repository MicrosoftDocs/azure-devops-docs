::: moniker range="<=azure-devops"

1. Select **Artifacts**, and then select your feed from the dropdown menu.

1. Select **Connect to feed**.

    :::image type="content" source="../../media/connect-to-feed-azure-devops-newnav.png" alt-text="Screenshot showing the Connect to feed pane in Azure Artifacts.":::

1. Select **NuGet.exe**.

    :::image type="content" source="../../media/nuget-connect-feed.png" alt-text="Screenshot showing the NuGet.exe connection type selected in the Connect to feed pane.":::

1. Follow the instructions in **Project setup** to set up your nuget.config file.

    :::image type="content" source="../../media/project-setup.png" alt-text="Screenshot showing the Project setup section in the Connect to feed pane.":::

::: moniker-end
