# Pull request commenter filtering

Filter pull request comments by one or more participants to focus on the conversations that matter to you. Your selections carry across the **Overview** and **Files** views, while each view retains its existing filters.

Matching conversations remain intact, so you can see the full discussion, including replies from other participants.

These planned improvements are subject to change.
