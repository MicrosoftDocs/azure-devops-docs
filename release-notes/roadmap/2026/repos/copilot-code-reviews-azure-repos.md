# Copilot Code Reviews for Azure Repos (public preview)

Copilot code reviews for Azure Repos enters public preview, bringing AI-assisted pull request reviews to Azure Repos. Copilot analyzes pull request changes, identifies potential issues, and suggests improvements so teams can address problems and improve code quality before merging.

To learn more, see [Copilot code reviews for Azure Repos](https://devblogs.microsoft.com/devops/copilot-code-reviews-for-azure-repos-public-preview/).

## Additional improvements coming

- Automatically resolve a comment when you apply its suggestion
- Add Copilot code review configuration changes to the audit log
- Support self-hosted runners
