### Windows Server 2025 with Visual Studio 2026 is generally available

Windows Server 2025 with Visual Studio 2026 is now generally available for Microsoft-hosted agents in Azure Pipelines. The `windows-2025` label continues to use Visual Studio 2022 and will transition to Visual Studio 2026 by November 15, 2026. We recommend that you transition to the latest available image.

For more information, see the [Windows Server 2025 image announcement](/azure/devops/pipelines/agents/hosted?tabs=windows-images%2Cyaml#software).

### Ubuntu 26.04 is generally available

Ubuntu 26.04 is now generally available for Microsoft-hosted agents in Azure Pipelines. To use this image, select the `ubuntu-26.04` image label.

For more information, see the [Ubuntu 26.04 image announcement](/azure/devops/pipelines/agents/hosted?tabs=windows-images%2Cyaml#software).
