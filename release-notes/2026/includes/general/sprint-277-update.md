### Enterprise Live Migration MCP Server Tools (preview)

[Enterprise Live Migrations (ELM)](https://learn.microsoft.com/azure/devops/repos/enterprise-live-migrations/overview) helps organizations migrate Azure DevOps repositories to GitHub Enterprise Cloud with data residency while minimizing disruption. We've added ELM tools to our Remote MCP Server, enabling you to streamline and automate repository migrations to GitHub.

These tools can be used to build custom agents and skills for repository migration tasks.

[Learn more](https://learn.microsoft.com/azure/devops/mcp-server/remote-mcp-server#enterprise-live-migration-preview) about the Remote MCP Server and the ELM tools.
